# Build 17 source comparison

Build 17 was assembled from three supplied website sources and the attached
cloud-migration reference image. The comparison favored verified content,
deployability, conversion value, and brand consistency over copying every older
page or claim.

| Source | Strong material retained | Material corrected or excluded |
|---|---|---|
| Build 09 Official Logo | Corporate/service positioning, M365 product emphasis, UAE industry coverage, official visual library, broader solution areas | Launcher branding, obsolete capacity-based pricing, unsupported native Teams wording, placeholder installer instructions |
| Modern SaaS source | Service taxonomy, product-page concept, project imagery, navigation ideas | Hard-coded product version, placeholder production URLs, public portal/status pages without live services, generic website-price content |
| GitHub Pages Build 15 | Customer-hosted architecture, safe Delta/Teams/throttling wording, responsive system, SEO, analytics, chatbot, consent, forms, release manifest, documentation | Retired Gmail contact, old licensing schedule, text-only branding, migration-only homepage emphasis |
| Attached visual references | Navy/cyan/violet migration direction, uniform dark pricing background, official ALZA logo | Applied with responsive sizing, high-contrast cards, and revised pricing hierarchy |

## Page decisions

- Added `m365-migration-suite.html` as the primary product landing page.
- Retained the deeper `platform.html` and `architecture.html` routes.
- Expanded `services.html`, `projects.html`, `about.html`, and
  `ai-solutions.html` with approved supplied imagery.
- Retained pricing, resources, documentation, legal, contact, thank-you, 404,
  and future-download routes from Build 15.
- Did not publish the old static status page because it was not connected to a
  monitoring provider.
- Did not publish the placeholder customer portal because no verified public
  endpoint or authentication workflow was supplied.
- Did not publish an installer because no verified signed EXE/MSI, checksum, or
  release metadata was supplied.
