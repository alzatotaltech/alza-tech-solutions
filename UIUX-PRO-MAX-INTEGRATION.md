# UI/UX Pro Max integration

UI/UX Pro Max is an AI-agent skill, not a JavaScript runtime dependency.

## Install into Codex for this repository
```bash
npm run uiux:install
```

The official skill uses Python-based search/design-system tooling. After installation, use it for page design, component refactoring, typography/color choices, responsive UX, accessibility review and pre-delivery QA.

The repository also contains `.codex/skills/alza-premium-web/SKILL.md` so ALZA-specific rules remain available even before the external skill is installed.
