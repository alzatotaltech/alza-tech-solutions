ALZA Website Build 31 – Responsive Edition

Implemented a mobile-first responsive layer in assets/css/responsive.css and loaded it after master.css on all 25 HTML pages.

Key changes:
- Mobile hamburger navigation up to 1151px; full desktop navigation from 1152px.
- Accessible menu state, Escape close, focus containment, outside-click handling, and resize synchronization.
- Fluid containers, typography, spacing, buttons, forms, cards, tables, media and page heroes.
- Flexible 1/2/3/5-column grid progression for phones, tablets, laptops and large monitors.
- Responsive pricing cards, workload tabs, architecture diagrams, contact/solutions media and footer.
- Horizontal scrolling for tab controls and tables where stacking would reduce usability.
- Mobile-friendly modal, consent banner, WhatsApp action and minimum 44px touch targets.
- Tested representative pages at 375px, 768px, 1024px, 1366px and 1920px for viewport overflow and navigation behavior.
